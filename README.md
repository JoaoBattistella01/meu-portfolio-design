# meu-portfolio-design

Este repositório foi criado como parte da atividade prática da trilha
GitHub Foundations, disponibilizada pela Microsoft Learn, para a
disciplina de Design Profissional.

## Objetivo

O objetivo deste repositório é aplicar na prática os conceitos de
versionamento de código aprendidos na trilha, incluindo:

- Criação e organização de commits
- Uso de branches separadas da branch principal
- Realização de merge/pull request
- Documentação do projeto via README

O conteúdo aqui será apresentado em sala como evidência prática da
conclusão da trilha GitHub Foundations.
